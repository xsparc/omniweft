## Tags and compatibility

Add native typed entity.tags.set(target,tags): at most eight unique ASCII identifiers, each 1..32 bytes, sorted deterministically, staged through Coordinator and advancing the entity authoring revision. Empty tags clear metadata. Tags never confer permissions. Existing root/untagged hierarchy diagnostic bytes remain exactly OWOBJ001/002; tagged states use OWOBJ003, adding tag-count uint32LE and length-prefixed ASCII tags after each live entity's format 2 payload. Any live tags select format 3; otherwise restore format 2 for live edges or format 1 for roots. This is diagnostic data, not a save migration. Existing remote/policy gateways deny tag operations before owner/sequence consumption and deny tagged observations; grants, quotas and SDK shapes remain unchanged.

## Native query authority and predicates

A single-owner native Session binds one exact World instance and an immutable host-issued ReadGrant. Explicit whole-world access or a generation-bearing identity allowlist is required; the default empty allowlist denies all. Optional read-region restriction is ANDed with identity access and requires complete actual world-space cube AABB containment. Tags never widen access. Constructor input is bounded before copying. Grant expiration and explicit close invalidate authority; no dynamic revocation/administration API is claimed. Trusted hosts bound the number of sessions; no global service-memory bound is claimed from per-session limits.

Query filters contain at most four unique bounded tags (AND semantics) and optional finite ordered AABB (inclusive intersection, distinct from grant containment). Use cached world transforms, including inherited rotation and signed/nonuniform leaf scale. Authoritative data remain immutable. Projection contains only authorized identity/generation, resource revision, world transform, tags and world bounds; never parent/local data, raw slot positions, unfiltered counts or canonical-world hashes. The grant intentionally includes world ID/revision metadata; it does not promise to conceal global revision activity. Unauthorized rows do not affect result size, cursor position or budgeting.

## Pagination, lifetime and resource contract

Retain one bounded set of authorized projected rows, UUID sorted. A native opaque cursor binds session identity, snapshot serial and authorized-row position. Query/filter/page limits are fixed for that snapshot; next accepts only its opaque cursor. Default/foreign/replaced/expired cursors return generic REQUIRES_RESYNC. Cursor copies/replay are idempotent; the absolute snapshot deadline never extends. Final pages have no next cursor, but earlier valid cursors remain replayable until replacement/expiry. World mutation/delete/reuse between pages cannot alter retained results; a successful fresh start replaces the retained snapshot. Rejected starts leave the existing lease intact. Close/expired-grant releases rows and forbids fresh starts. Expiration releases data on the next API call or destruction; no background service is introduced.

Input counts/lengths/page limits are checked before snapshot copying or serialization. At most 1024 world slots, 64 requested rows/page, 4096 UTF-8 JSON bytes/response and 1 MiB retained projected payload are allowed, additionally capped by the host grant. Snapshot staging may temporarily coexist with the previous bounded result set. Complete response framing is charged before assembling public output; one row that cannot fit fails without partial output or cursor advance. The fixed-size opaque native cursor is not a wire token and is never serialized. No remote query endpoint, provider, dependency or persistence is added.
