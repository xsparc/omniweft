# PR-017 bounded glTF mesh import

Authorized by [the adopted roadmap](AUTHORIZATION.md). Coordinator branch `codex/pr-017-gltf-import` starts from actual PR #23 merge `2e8f05b5d55f02052c17b4a505f54abff9784af1`. Its tree matches reviewed delivery `920e7156265f8a9ce728acbe398a9977112cbbb6`; all six post-merge checks and both actual-merge native manifests passed and were verified. PR-016 is integrated.

Implement one native typed GLB import request containing bytes, source/license provenance and expected Catalog revision. Validate and stage a complete detached scene, immutable source manifest and one-asset bundle before ordinary Catalog Import publication. Retain the original GLB under `model/gltf-binary`; return its full AssetId/Manifest and importer profile version with source-ordered geometry, material references, node matrices and bounds. Rejection returns no scene and preserves the complete Catalog and caller input. Success advances the Catalog revision exactly once, including deduplication. No throwing construction follows publication.

The bounded profile accepts GLB 2.0 with one internal buffer, one scene, indexed triangles, float32 POSITION and unsigned 8/16/32-bit indices. TRS nodes use column-major binary64 matrices and parent-world times local composition. Preserve vertex/index order and absent material references. Material data supports bounded names, base-color/metallic/roughness factors, double-sided and opaque mode only. No World attachment, cooked format, remote endpoint, renderer, textures, normals/UVs, skins, morphs, animations, cameras, matrix-authored nodes, external/data URI resolution, new dependency, persistence migration, GPU or physics claim. Unsupported features fail explicitly; imported data grants no authority.

Limits: GLB 65536 bytes, JSON chunk 16384 bytes, JSON depth 16, SAX events 4096 and each decoded key/string 256 bytes. Validate duplicate decoded keys and bounds before constructing a DOM through existing pinned nlohmann/json. Cap buffer views/accessors at eight each, meshes at four, total primitives at four, nodes at eight and materials at four. Per primitive cap 256 vertices/768 indices; cap unique decoded data and materialized output separately at 1024 vertices/3072 indices. Check range arithmetic, declared-buffer bounds excluding padding, alignment, strides, restart sentinels, matching POSITION extrema and all references. Validate all declared entries, including unused ones, and the full forest for cycles/duplicate parents. Unknown extra GLB chunks may be skipped within the file budget; duplicate JSON/BIN chunks reject.

Absolute positions/translations are bounded at 1e6, scales at 1e3; negative/zero scales are allowed. Quaternion squared norm must be within 1e-6 of one and is explicitly normalized once. Composed matrices and transformed positions must remain finite; world coordinates are bounded at 1e12. Compute node bounds from transformed vertices of that node's mesh; aggregate only selected-scene reachable mesh instances. Reject an empty selected scene. The seed-7 fixture uses integer/power-of-two TRS and quaternion (0,0,1,0), so expected geometry, matrices and bounds compare exactly. Any separate nonexact native fixture uses a declared absolute tolerance of 1e-12; no general cross-platform bitwise promise follows.

The `meshes.import_gltf` example writes and reads a generated tiny GLB, imports it through the public typed API, demonstrates deduplication and distinct provenance, retains complete states and proves malformed indices/nonfinite attributes/required extensions/resource caps fail atomically before valid recovery. Native tests extend this to truncation, schema/JSON ambiguity, arithmetic/alignment/stride, hierarchy/material references, stale revision and Catalog quota. The independent Python oracle encodes fixture bytes itself, derives literal expected transforms/bounds/materials and source hashes, validates actual file bytes and full rejection/recovery states. Corruption tests must reject misleading reports.

Coordinator owns this plan, shared ledger, example, independent oracle, CMake/CI and public documentation. An isolated implementation helper owns the new glTF header/module/native tests. Independent architecture review selected this profile; independent implementation/oracle and archive reviews remain required. Run pinned local Windows tests, planning validation and actual hosted Windows/Linux checks; retain clean source-bound evidence and verify both hosted manifests. CPU checks do not establish GPU support. Record OpenSteward foreign-registry checks honestly against existing Omniweft governance.

The existing asset bundle and World save formats remain unchanged. Original GLB bytes retain their source/license assertions as data, not authenticated licensing claims. Roll back the additive importer through a PR and preserve source files. Draft publication is authorized; maintainer certification/review and manual merge remain required before PR-018.

Format reference: [Khronos glTF 2.0 specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html), especially GLB layout, accessors and node transformations. The limits and supported subset above are Omniweft's importer profile, not a claim of full glTF support.
