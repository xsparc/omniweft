# PR-013: bounded recorded command replay

Authority: adopted roadmap and maintainer continuation in [AUTHORIZATION.md](AUTHORIZATION.md). Base is verified PR-012 merge `d8f49dc97d97ef62600b58b299c24527b94bbb4c`. One native CPU behavior; no phase promotion, new ADR, durable storage, remote endpoint, physics, live provider, save-format migration or new authority. Root owns implementation and ledger writes; independent source/oracle/evidence review is required.

Opt-in Recorder binds an empty revision-zero World with at most eight slots. It records up to eight accepted batches of four operations, a 16 KiB canonical-command limit and bounded exact diagnostic checkpoints. Assign accepted sequence and preserve caller-supplied nondecreasing boundary ticks; this is authoring order, not a simulation rewind. Sanitize by construction: record operations, budgets, expected revision, resolved creation identities and checkpoints, never authentication epochs or full request headers. Outside edits reject both further recording and export.

Extend the trusted Coordinator with a prepublication observer: prepare receives final staged snapshot and receipt before swap, may allocate/reject, and publish is noexcept after world and policy publication. Preserve existing guard ordering and ordinary calls. Extract read-only canonical encoding for detached snapshots. Replay uses explicit recorded creation bindings, verifies each against allocator/temp/world/generation contracts, consumes them in operation order, and rejects missing/extra/mismatched bindings without fallback.

A typed versioned ReplayLog records world/seed/slot limits and the immutable builtin.unit_cube revision-1 asset contract, including exact canonical face/color/triangle descriptor bytes and their SHA-256 identity. This is an in-memory diagnostic replay record, not a file persistence format. Replay validates all schema, asset, count, string and command bounds before executing into a private fresh World. It checks each complete checkpoint before exposing any result. A corrupt later record returns no world, never a usable prefix. No policy/session/lease state is replayed or granted.

Tests and world.replay must independently verify exact identities/generations, allocator tombstones, revisions, all checkpoint bytes, same-tick accepted ordering, rejected batches omitted, same-batch create/delete/reuse, full-log atomic rejection, outside-edit detection, missing assets, unsupported schemas, late corrupt records and recovery with the unchanged valid log. Include prepublication observer/staging failure and native input bounds. Required local Windows and hosted Windows/Linux CPU checks; no GPU claim. Retain a clean-candidate JSON-only evidence archive with independent review before authorized draft delivery. Keep PR-014 proposed until integration.

Apply OpenSteward scope/traceability through the existing Omniweft ledger and handoffs. Its foreign-registry checker is not a replacement authority or passed gate; record actual checker results and use the adopted project gates.
