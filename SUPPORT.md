# Support

For design questions, usage discussion or contributor coordination, use [GitHub Discussions](https://github.com/xsparc/omniweft/discussions). For reproducible defects and bounded feature proposals, use [Issues](https://github.com/xsparc/omniweft/issues).

Include the relevant document/work item today, or exact engine commit, OS, device/driver, command and minimal example once implementation exists. Report whether behavior is planned, implemented or verified. Never include API keys, access tokens or private world content unnecessarily.

There is no production support service or guaranteed response time. Security issues follow [SECURITY.md](SECURITY.md), and conduct concerns follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
