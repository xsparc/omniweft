# Code of Conduct

Omniweft welcomes contributors of different backgrounds and experience. Treat people with respect, focus criticism on work, make room for questions, and accept correction when evidence warrants it.

Harassment, threats, discriminatory abuse, sexual harassment, deliberate intimidation, disclosure of another person's private information, and repeated disruptive behavior are unacceptable. These expectations apply in repository issues, PRs, discussions and official project spaces, including representing the project elsewhere.

The project steward may edit or remove inappropriate content, warn participants, temporarily limit participation or remove access according to severity and repeated behavior. Apply decisions consistently, explain non-sensitive reasons and offer reconsideration when new information exists. Do not retaliate against good-faith reports.

For non-sensitive project moderation concerns, contact `@xsparc` through an issue or discussion without posting personal details. If you already have a private channel to the steward, use it for confidential concerns. A dedicated confidential project contact has not yet been designated. For harassment or abuse on GitHub, use [GitHub's private abuse-reporting process](https://docs.github.com/en/site-policy/acceptable-use-policies/reporting-abuse-or-spam); that process is operated by GitHub, not the project steward. Do not post confidential reports publicly.

Reports should include relevant links, behavior, approximate dates and desired response where safe. Share report details only as needed for investigation and platform requirements. This is a project-specific policy under the repository license, not a claim of adoption or certification by another conduct program.
