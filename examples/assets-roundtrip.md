The seed-7 fixture imports opaque generated bytes with source/license manifests through typed revision-checked Catalog commands. It proves identical-manifest deduplication, distinct provenance sharing one blob, canonical export through an actual bundle file, fresh import without owner roots, and raw/RLE8 equivalence. Explicit owner history roots protect an old manifest while current roots change; later collection drops the manifest and retains its shared blob until the final rooted manifest is removed. Valid reimport and a fresh history root demonstrate recovery.

```sh
omniweft_examples --example assets.roundtrip --headless --seed 7 --verify --output artifacts/assets.roundtrip
python tests/assets_oracle.py --executable <build>/omniweft_examples --native-test <build>/assets_native_test --evidence artifacts/assets
```

Use `.exe` for Windows executables and a fresh output/evidence directory. Build through the pinned [bootstrap instructions](platform-bootstrap.md). The example writes `result.json` and `seed7.owas`. The oracle independently computes complete manifests/content hashes, literal snapshots/receipts and canonical bytes, reads the actual bundle file, and checks every accepted transition. The corruption selftest rejects altered identities, provenance, bytes, revisions, receipts, retention and rejection reports, including incorrect types and unexpected fields.

Missing/extra blobs, traversal identifiers, content/manifest hash mismatch, unsupported schema/codec, duplicate entries, decompression overflow/zero/truncation, decoded budget, trailing data, stale revision and unknown roots reject atomically. Full before/after snapshots and unchanged input bytes are checked; a final valid mutation recovers at the next revision. Native boundary tests cover the remaining catalog/string/root/bundle/expansion limits.

History roots are owner-supplied retention sets, not automatic World undo or save-file integration. Imported provenance is retained attribution data, not authenticated license authority. No existing save-format migration, glTF loader, filesystem extraction, remote asset endpoint, durable asset store, GPU or physics support is claimed. Reverting the additive module must preserve original bundle files.
